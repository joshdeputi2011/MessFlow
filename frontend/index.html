WHY 5%?

Small safety buffer, not overproduction.

MessFlow uses a deliberately simple formula suitable for a mini-project: confirmed YES responses × 1.05, rounded up.

Recommended servings = ⌈ YES × 1.05 ⌉

In a real deployment, the buffer could later be tuned using historical wastage and attendance data.

Data model

Partition key: dateMeal = "2026-09-02#dinner"
Sort key: studentId = "23BEE101"
response = "YES"
updatedAt = "2026-09-01T12:30:00Z"

Because dateMeal + studentId is unique, the same student can update their answer without creating duplicate records for the same meal.
